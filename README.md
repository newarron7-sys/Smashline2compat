# smashline2-compat

Plugin Skyline pour Smash Bros Ultimate 13.0.4 avec Smashline 1.6.6 : recrée les fonctions de Smashline 2.0 (clone_weapon, enable_weapon_module, replace_weapon_vtable, replace_fighter_vtable_costume, get_original_fighter_vtable, update_weapon_count) sous les noms `smashlinx_*`, pour des movesets faits pour Smashline 2.0.

Le fichier compilé `libsmashline2_compat.nro` est publié sur la branche `nro`.
